\chapter{Introduction}

This template uses a dark navy base, electric blue and purple accents, and a clean sans-serif typeface to match the ROAd logo. It is intended for reports, design documents, technical documentation and project deliveries.

\begin{roadbox}{Design direction}
The visual style is based on three ideas: high contrast, clean geometry and dynamic blue-purple accents. The body text remains simple, while sections, boxes and figure frames carry the identity of the app.
\end{roadbox}

\section{Section style}
Use sections for the main blocks of the document. The numbered label is dark and compact, while the title remains clean and readable.

\subsection{Subsection style}
Subsections use the secondary deep blue. Sub-subsections use the purple accent.

\begin{keybox}{Key point}
Use this box for important definitions, architectural choices, requirements or results.
\end{keybox}

\begin{warningbox}{Attention}
Use this box for limitations, assumptions, risks or implementation notes.
\end{warningbox}
